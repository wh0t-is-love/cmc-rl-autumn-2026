## Как запустить полный прогон

**Colab (рекомендуется, ~1.5 ч на GPU):** загрузить `a2c-optional-solved.ipynb`,
Runtime → Run all. Setup-ячейка сама ставит зависимости, патчит несовместимость
gymnasium 1.4 (atari из ale-py вместо shimmy) и скачивает 3 helper-файла курса.

**Локально / ноут CPU (~6-8 ч):** python 3.10+, затем:

    pip install torch --index-url https://download.pytorch.org/whl/cpu
    pip install "gymnasium[atari,accept-rom-license]" opencv-python-headless tensorboardX "shimmy[atari]==1.3.0"
    python test_targets.py   # юнит-тесты должны пройти
    python train.py --nenvs 16 --total-steps 10000000 --out runs/run.jsonl
    # ступень 2 (победная): resume до 15M с LR-рестартом и сниженной энтропией
    python train.py --nenvs 16 --total-steps 15000000 --entropy-coef 0.005 \
        --out runs/run.jsonl --resume auto

## Скор

Баллы считает `reward_mean_100` — средний **сырой** (не обрезанный ±1) reward
за последние 100 эпизодов. Обучение идёт на clipped-наградах — это нормально,
что «тренировочные» награды выглядят маленькими; смотреть надо на кривую
`reward_mean_100`. Random-агент на Space Invaders ≈ 150–200.

## Ключевые места, где обычно ломается

1. `policy.act` без `no_grad` / попытка учиться по stored `log_probs` (нет графа) —
   форвард для лоссов пересчитывается в `A2C._training_forward`.
2. `ComputeValueTargets`: считать с конца; при `resets[t]=True` будущее отрезано,
   включая bootstrap `v(s_{t+T})`, если роллаут кончился на reset.
3. `MergeTimeBatch`: все ключи выравниваются в одном порядке `(t, n) → t*N + n`;
   `value_targets` приходит уже массивом `(T, N)` — его тоже надо схлопнуть.
4. Гиперпараметры: RMSprop lr 7e-4 → линейно в 0, alpha 0.99, eps 1e-5,
   grad clip 0.5, value_loss_coef 0.25, entropy_coef 0.01, nsteps=5.
